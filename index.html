Заполни только нужные поля — получи все практические

Заполняй только те показатели, которые знаешь. Остальные поля можно оставить пустыми: для учебного примера автоматически подставятся значения с пометкой *. В режиме для тетради сохранены обязательные протоколы и таблицы, а справочные страницы скрыты. В предпросмотре можно включить их при необходимости.

Любые неподтверждённые данные, автоматически подставленные вместо пустого поля, помечаются в отчёте знаком *. Подставленные числа показывают расчёт, но не подтверждают, что тест проводился.

Программа занятия

Незаполненные поля получают немного разные учебные примеры при каждой новой генерации. В пределах одного открытого отчёта значения остаются постоянными. Числа со знаком * — условные, а не измеренные.
